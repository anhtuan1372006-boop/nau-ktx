# Cổng nội trú NAU trên GitHub Pages

Website: https://anhtuan1372006-boop.github.io/nau-ktx/

Bản công khai đã build gồm giao diện, hình ảnh, cẩm nang và danh sách phòng giả lập đã lưu. Cổng vẫn mở khi máy chủ thử nghiệm dừng. Không chứa API .NET, SQL Server, tài liệu riêng tư hoặc dữ liệu sinh viên.

Mục Đăng nhập hiển thị 5 tài khoản minh họa và dẫn tới máy chủ thử nghiệm đầy đủ. Máy chủ đó có thể tự dừng; GitHub Pages không chạy cơ sở dữ liệu hay xử lý nghiệp vụ.

Đây là bản phần mềm đồ án, chưa phải cổng vận hành chính thức của nhà trường. Địa chỉ ổn định trong thời gian kho và GitHub Pages được duy trì; không có cam kết truy cập vĩnh viễn hoặc không bao giờ lỗi.

Bản build được cập nhật từ dự án KTX bằng pnpm build:pages và tools/publish-pages.ps1. Giữ BOXANH ở địa chỉ github.io gốc.
